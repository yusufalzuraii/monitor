# 📡 مراقب أخبار وكالة وفا

نظام يراقب صفحة [آخر الأخبار](https://www.wafa.ps/Pages/LastNews) في وكالة الأنباء والمعلومات الفلسطينية (وفا)، وكل خبر جديد ينزل يفوت عليه، يستخرج **العنوان + النص الكامل النظيف + الصورة + وقت النشر**، ويبعتهم فوراً على **تيلجرام**.

---

## ⚡ التركيب السريع (10 دقائق)

### 1) إنشاء بوت تيلجرام

1. افتح تيلجرام وابحث عن **@BotFather**.
2. أرسل `/newbot` واتبع الخطوات (اسم البوت، ثم يوزرنيم ينتهي بـ `bot`).
3. رح يعطيك توكن شكله:
   ```
   7123456789:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw
   ```
   احفظه — هذا `TELEGRAM_BOT_TOKEN`.

### 2) الحصول على `TELEGRAM_CHAT_ID`

**لو بدك الأخبار تجيك على الخاص:**

1. ابحث عن البوت اللي عملته واضغط **Start** (مهم جداً — البوت ما بيقدر يراسلك قبل ما تبدأ معه).
2. افتح هذا الرابط في المتصفح بعد ما تحط التوكن:
   ```
   https://api.telegram.org/bot<التوكن>/getUpdates
   ```
3. دوّر على `"chat":{"id":123456789` — هذا الرقم هو `TELEGRAM_CHAT_ID`.

**لو بدك الأخبار تنزل على قناة:**

1. أنشئ قناة، وأضف البوت كـ **Admin** مع صلاحية "نشر الرسائل".
2. استخدم يوزرنيم القناة مباشرة كـ chat id: `@my_channel_name`
   (أو للقنوات الخاصة: انشر رسالة بالقناة، حوّلها للبوت، وشوف `getUpdates` — الرقم بيبدأ بـ `-100`).

### 3) رفع المشروع على GitHub

```bash
cd wafa-monitor
git init
git add .
git commit -m "مراقب أخبار وفا"
git branch -M main
git remote add origin https://github.com/<اسم-حسابك>/wafa-monitor.git
git push -u origin main
```

> 💡 خلّي الريبو **Private** لو حابب — GitHub Actions بيشتغل مجاناً على الاثنين.

### 4) إضافة المفاتيح في GitHub

من صفحة الريبو: **Settings → Secrets and variables → Actions → New repository secret**

| الاسم | القيمة |
|---|---|
| `TELEGRAM_BOT_TOKEN` | التوكن من BotFather |
| `TELEGRAM_CHAT_ID` | الرقم أو `@channel_name` |

### 5) التشغيل

**Actions → مراقب أخبار وفا → Run workflow**

- **الجولة الأولى** بتسجّل كل الأخبار الموجودة حالياً كـ"قديمة" **بدون ما ترسل شي** — هيك ما بينفجر تيلجرامك بـ 50 رسالة.
- **من الجولة الثانية وطالع**، أي خبر جديد بيوصلك خلال دقايق. ✅

بعد هيك بيشتغل لحاله **كل 10 دقائق، 24 ساعة**، حتى لو جهازك مسكّر.

## 🧪 الاختبار قبل التشغيل (موصى به)

على جهازك:

```bash
pip install -r requirements.txt

# 1) شوف شو بيستخرج فعلياً من الموقع — بدون ما يرسل أي شي
python monitor.py --test

# 2) تأكد إن إعدادات تيلجرام صحيحة
export TELEGRAM_BOT_TOKEN="التوكن"
export TELEGRAM_CHAT_ID="الآيدي"
python monitor.py --test-telegram

# 3) اختبارات منطق الاستخراج (بدون إنترنت)
python tests/test_extraction.py
```

`--test` بيطبع العنوان والمدينة والوقت والصورة وأول 800 حرف + آخر 200 حرف من كل خبر — راجعها وتأكد إن النص طالع نظيف قبل ما تفعّل الإرسال.

> ✅ `--test` **ما بيلمس ملف الحالة نهائياً** — فش خطر إنه يعتبر أخبار موجودة كـ"مرسلة".

**لو وقت النشر أو الصورة طلعوا غلط**، شغّل سكربت التشخيص وابعت المخرجات:

```bash
python inspect_page.py                     # يفحص أحدث خبر
python inspect_page.py <رابط خبر معيّن>     # يفحص خبر محدد
```

> ⚠️ لازم تكتب `python` قبل اسم الملف. لو كتبت `inspect_page.py` لحاله، ويندوز رح يفتحه بالمحرر بدل ما يشغّله.

بيطبع كل وسوم `meta` و `JSON-LD` وعناصر الوقت والصور المتاحة بالصفحة.

## ⚙️ إعدادات إضافية (اختيارية)

من **Settings → Secrets and variables → Actions → Variables**:

| المتغير | الافتراضي | الوظيفة |
|---|---|---|
| `KEYWORDS` | (فاضي) | فلترة: يرسل فقط الأخبار اللي فيها وحدة من الكلمات. مثال: `غزة,الضفة,القدس,الأسرى` |
| `MAX_PER_RUN` | `8` | أقصى عدد رسائل بالجولة الواحدة (حماية من الفيضان) |
| `SEND_IMAGES` | `1` | حطّه `0` لو ما بدك صور |
| `MAX_BODY_CHARS` | `3500` | أقصى طول للخبر بالرسالة؛ الأطول بينقص مع رابط "تابع الخبر كاملاً". حطّه `0` للنص كامل مهما طال |
| `POLL_SECONDS` | `300` | فقط لوضع `--loop` على جهازك/سيرفرك |

| `POLL_SECONDS` | `120` | كل كم ثانية يفحص (داخل الجولة الوحدة) |

### ⏱️ كيف بنوصل لفحص كل دقيقتين؟

جدولة GitHub (cron) **أقل شي كل 5 دقائق**، وبتتأخر أحياناً 10-15 دقيقة وقت الازدحام. فما بنعتمد عليها للتوقيت:

- كل تشغيل بيفضل **شغّال 14 دقيقة** وبيفحص الموقع **كل دقيقتين** جوّاته (`--loop --duration 840`).
- الجدولة كل 15 دقيقة وظيفتها **إعادة تشغيل السلسلة** بس، مش الفحص نفسه.
- `concurrency` بتمنع تشغيل جولتين مع بعض، والجولة الجديدة بتستنى دورها — فما في رسائل مكررة.

> ⚠️ **لازم الريبو يكون Public.** الدقائق بتكون مجانية بلا حدود للريبوهات العامة. لو خليته Private رح تحرق الـ2000 دقيقة المجانية خلال يومين ويوقف. الريبو ما فيه أي أسرار — التوكن محفوظ بـ Secrets مش بالكود.

**بصراحة:** هالطريقة بتعطيك ~دقيقتين معظم الوقت، بس ممكن تصير فجوة 5-15 دقيقة أحياناً لما GitHub يتأخر بتشغيل الجدولة. لو بدك دقيقتين **مضمونة 100%**، التشغيل على جهازك أو VPS هو الحل (تحت 👇).

## 🖥️ تشغيل بديل: على جهازك (دقيقتين مضمونة)

**ويندوز** — أنشئ ملف `run.bat` جنب `monitor.py`:

```bat
@echo off
cd /d "%~dp0"
set TELEGRAM_BOT_TOKEN=حط_التوكن_هون
set TELEGRAM_CHAT_ID=حط_الايدي_هون
set POLL_SECONDS=120
python monitor.py --loop
```

دبل كليك عليه ويفضل شغّال. **لتشغيله تلقائياً مع الويندوز:**

1. `Win + R` → اكتب `shell:startup` → Enter
2. انسخ اختصار لـ `run.bat` جوّا المجلد اللي فتح

**لينكس / VPS (systemd)** — أنشئ `/etc/systemd/system/wafa.service`:

```ini
[Unit]
Description=Wafa News Monitor
After=network-online.target

[Service]
WorkingDirectory=/opt/wafa-monitor
Environment=TELEGRAM_BOT_TOKEN=...
Environment=TELEGRAM_CHAT_ID=...
Environment=POLL_SECONDS=120
ExecStart=/usr/bin/python3 monitor.py --loop
Restart=always
RestartSec=30

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now wafa
```

## 🛠️ كيف بيشتغل (باختصار)

| المرحلة | الطريقة |
|---|---|
| **كشف الأخبار** | يقرأ صفحة آخر الأخبار ويلتقط كل رابط شكله `/news/YYYY/M/D/<عنوان>-<رقم>`. **ما بيعتمد على أسماء الكلاسات** — لأنها بتتغير مع أي تحديث للموقع، بينما شكل الرابط ثابت. |
| **منع التكرار** | كل خبر له رقم فريد متزايد. الأرقام المرسلة محفوظة في `state/seen.json`، وبينحفظ **بعد كل رسالة** — فلو وقع السكربت بالنص، ما في خبر بينعاد. |
| **استخراج النص** | ثلاث طبقات بالترتيب: (1) `JSON-LD` وهي الأنظف، (2) وسوم `og:`، (3) تحليل الـ DOM واختيار الحاوية الأكثر كثافة بالفقرات العربية — مع حذف الإعلانات والفوتر و"اقرأ أيضاً" والشريط الجانبي. لو تغيّر تصميم الموقع، الطبقات البديلة بتغطّي. |
| **تنظيف خاص بوفا** | سطر الافتتاح «رام الله 15-8-2026 وفا-» بينفصل وبيطلع المدينة والتاريخ منه (بينعرضوا بشكل منظم بالرسالة بدل ما يكونوا ملزوقين بالنص)، وتوقيع المحرر بالآخر («و.أ» ، «د.ذ/ و.أ») بينحذف. |
| **وقت النشر** | خمس طبقات: `JSON-LD` → وسوم `meta` → عناصر `<time>` أو كلاسات فيها date/نشر → تاريخ سطر الافتتاح → تاريخ الرابط. **ما بيخترع وقت وهمي** — لو ما لقي ساعة، بيعرض التاريخ لحاله بدل وقت التشغيل. |
| **الصورة** | `og:image` → `JSON-LD` → أول صورة حقيقية جوّا الخبر (مع تجاهل اللوغو والأيقونات والإعلانات)، وبعدها بيحاول يرقّي النسخة المصغّرة `Small` لنسخة أوضح — **بس بعد ما يتأكد إن الرابط الجديد شغّال**، والنتيجة بتتخزّن فما بيفحص مع كل خبر. |
| **الإرسال** | صورة الخبر بتنعرض **فوق** النص عبر معاينة رابط مخفية — هيك بيوصل نص لغاية 4096 حرف مع الصورة، بدل حد الـ 1024 تبع الكابشن العادي. النص الأطول بينقسم على حدود الفقرات (مش بنص كلمة). |
| **المتانة** | إعادة محاولة مع تراجع تدريجي على أخطاء الشبكة و403/429/5xx، احترام `retry_after` من تيلجرام، و`concurrency` في الـ workflow يمنع تشغيل جولتين بنفس الوقت. |

## ❓ حل المشاكل

**ما وصلني ولا خبر**
- الجولة الأولى **مقصود** ما ترسل — انتظر خبر جديد ينزل على وفا.
- تأكد إنك ضغطت **Start** مع البوت (لو خاص) أو إن البوت **Admin** بالقناة.
- شغّل `python monitor.py --test-telegram`.

**وصلتني أخبار مكررة**
- غالباً فشل حفظ `state/seen.json` — افحص خطوة "حفظ ذاكرة الأخبار" في سجل الـ Actions. تأكد إن `permissions: contents: write` موجودة (هي موجودة بالملف).

**وصلتني صورة غلط (لوغو أو أيقونة)**
- الفلتر بيرفض `.gif` و `.svg` ومسار `PublicImg` وأي رابط فيه logo/icon/banner/share. لو ظهر نوع جديد، أضف كلمة مميزة منه لـ `BAD_IMAGE_HINTS` في `monitor.py`.
- معظم أخبار وفا **نصية بلا صور** — هذا طبيعي مش خلل.

**النص ناقص أو مبتور**
- شغّل `python monitor.py --test` وشوف الطول المطبوع. لو مشكلة استمرت، غالباً الموقع غيّر بنيته — أرسلي مخرجات `--test` وبعدّل طبقة الاستخراج.

**خطأ 403 من الموقع في GitHub Actions**
- الموقع خلف Cloudflare، ونادراً بيرفض عناوين سيرفرات GitHub. السكربت بيعيد المحاولة تلقائياً. لو صار دائم، الحل تشغّله على جهازك أو VPS بالطريقة الموجودة فوق (`--loop`) — نفس الكود بالضبط.

**الجدولة بتتأخر**
- طبيعي في GitHub Actions وقت الازدحام (أحياناً 5-15 دقيقة). لو بدك دقة عالية بالثواني، التشغيل على VPS أدق.
