1 حدّث الملفات دقيقة

  1. فك ضغط wafa-monitor.zip الجديد فوق مجلدك القديم — اختر Replace / استبدال الكل.
  2. افتح Command Prompt بالمجلد وشغّل تأكيد أخير:
cd C:\Users\yusuf\Desktop\wafa-monitor
python monitor.py --test
المفروض هلق كل الأخبار تطلع الصورة : (لا يوجد) ما عدا خبر «الأوامر العسكرية» — لأن الباقي فعلاً بلا صور وكان بياخد الصورة الافتراضية LargeDefualt.jpg بالغلط.

2 تأكد إن تيلجرام شغّال دقيقة

بنفس نافذة الـ Command Prompt (بدّل القيم بتاعتك):

set TELEGRAM_BOT_TOKEN=7123456789:AAHdqTcv...
set TELEGRAM_CHAT_ID=123456789
python monitor.py --test-telegram
لازم توصلك رسالة «✅ مراقب وفا — الإعدادات صحيحة» على تيلجرام.
لو طلع chat not found → ما ضغطت Start مع البوت، أو الـ chat id غلط.
لو طلع Unauthorized → التوكن ناقص أو فيه مسافة زايدة.
لا تكمّل للخطوة الجاية قبل ما توصلك رسالة التجربة. هيك بتتأكد إن المشكلة (لو صارت لاحقاً) مش من إعدادات البوت.

3 أنشئ ريبو على GitHub دقيقتين

  1. افتح github.com/new
  2. Repository name: wafa-monitor
  3. اختر Public ← مهم جداً، اقرأ التنبيه تحت
  4. لا تأشّر على أي شي من Add README أو .gitignore
  5. اضغط Create repository
ليش Public إجباري؟ عشان الفحص يصير كل دقيقتين، النظام بيفضل شغّال طول الوقت على GitHub. الريبوهات العامة دقائقها مجانية بلا حدود، أما الخاصة فعندها 2000 دقيقة بالشهر — رح تخلص خلال يومين ويوقف النظام.

هل في خطر؟ لا. التوكن والـ chat id بينحفظوا بـ Secrets (مشفّرة ومخفية)، مش بالكود. اللي بيصير عام هو كود السكربت بس.

4 ارفع الملفات دقيقتين

بالـ Command Prompt جوّا المجلد (بدّل USERNAME باسم حسابك):

git init
git add .
git commit -m "wafa news monitor"
git branch -M main
git remote add origin https://github.com/USERNAME/wafa-monitor.git
git push -u origin main
أول مرة رح يطلب تسجيل دخول — بيفتح نافذة متصفح، سجّل دخول لحسابك وخلص.
لو ما عندك git: نزّله من git-scm.com (Next → Next → Install).
لو طلع remote origin already exists شغّل: git remote set-url origin https://github.com/USERNAME/wafa-monitor.git

6 فعّل وشغّل دقيقة

  1. افتح تبويب Actions بالريبو
  2. لو ظهرت رسالة صفراء، اضغط I understand my workflows, go ahead and enable them
  3. من القائمة اليسار اختر مراقب أخبار وفا
  4. يمين ← Run workflow ← Run workflow
التشغيل الأول ما بيرسل ولا خبر — هذا مقصود. بيسجّل الـ41 خبر الموجودين كـ«قديمة» حتى ما ينفجر تيلجرامك. من بعدها أي خبر جديد بينزل على وفا بيوصلك خلال دقيقتين.
اضغط على التشغيل الجاري لتشوف السجل الحي. رح تلاقي سطر ▶️ تشغيل مستمر — فحص كل 120 ثانية، لمدة 14 دقيقة

7 تأكد إنه فعلاً شغّال بعد ساعة

  • ارجع لتبويب Actions — لازم تشوف تشغيلات متتالية بعلامة ✅ خضراء.
  • افتح ملف state/seen.json بالريبو — رقم last_id لازم يكبر مع الوقت.
  • أول خبر جديد ينزل على وفا لازم يوصلك خلال دقيقتين.
وفا بتنشر تقريباً 40-60 خبر باليوم، فأول خبر ممكن يوصلك خلال دقائق أو بعد نص ساعة حسب وقت النشر.

⏱️ كيف بيتحقق الفحص كل دقيقتين؟

جدولة GitHub أقل شي كل 5 دقائق، وبتتأخر أحياناً. فما اعتمدنا عليها للتوقيت:

  • كل تشغيل بيفضل شغّال 14 دقيقة وبيفحص وفا كل دقيقتين جوّاته.
  • الجدولة كل 15 دقيقة وظيفتها إعادة تشغيل السلسلة بس.
  • إعداد concurrency بيمنع تشغيل جولتين مع بعض — فما في رسائل مكررة.
بصراحة: هالطريقة بتعطيك دقيقتين معظم الوقت، بس ساعة الازدحام ممكن تصير فجوة 5-15 دقيقة لما GitHub يتأخر بتشغيل الجدولة. لو بدك دقيقتين مضمونة 100%، شوف الخيار تحت.

💻 خيار إضافي: تشغيل على جهازك (دقيقتين مضمونة)

أنشئ ملف run.bat جنب monitor.py وحط فيه:

@echo off
cd /d "%~dp0"
set TELEGRAM_BOT_TOKEN=التوكن_تبعك
set TELEGRAM_CHAT_ID=الايدي_تبعك
set POLL_SECONDS=120
python monitor.py --loop

دبل كليك عليه ويفضل شغّال. لتشغيله تلقائياً مع الويندوز: Win + R ← اكتب shell:startup ← Enter ← انسخ اختصار لـ run.bat جوّا المجلد.

لا تشغّل الاثنين مع بعض (جهازك + GitHub) — عندهم ذاكرتين منفصلتين وكل خبر رح يوصلك مرتين. اختار واحد: إما GitHub (24/7 بدون جهازك) أو جهازك (توقيت مضبوط بس لازم يضل شغّال).
